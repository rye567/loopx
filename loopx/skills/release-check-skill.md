# 发布检查技能

## 目的

准备发布证据，但不自动执行不安全发布动作。

## 输入

- 质量报告、测试报告、变更摘要、发布标准和部署/CI 约定。

## 步骤

1. 识别配置、数据库、兼容性和外部依赖变化。
2. 定义部署、回滚、监控和观测。
3. 区分本地验证、CI 必需验证和人工验证。
4. commit、push、部署或生产影响动作要求人工批准。

## 输出

- 发布就绪产物、剩余风险和人工批准要求。

## 通过标准

- 回滚和观测已定义或说明不适用；验证缺口未隐藏；未批准不执行发布动作。

## 失败处理

影响分析缺失回方案设计；证据缺失回测试执行；需要人工决策时阻塞。
