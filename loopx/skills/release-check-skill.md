# 发布检查技能

## 目的

准备发布证据，但不自动执行不安全的发布动作。

## 输入

- 已通过的质量报告。
- 测试报告。
- 变更文件摘要。
- 发布标准。
- 项目的部署或 CI 约定。

## 步骤

1. 识别配置、数据库、兼容性和外部依赖变化。
2. 定义部署和回滚步骤。
3. 定义监控和观测点。
4. 区分本地验证、CI 必需验证和人工验证。
5. commit、push、部署或生产影响动作必须要求人工批准。

## 输出

- 发布就绪产物。
- 剩余风险列表。
- 人工批准要求。

## 通过标准

- 回滚和观测已定义，或说明不适用原因。
- 验证缺口没有被隐藏。
- 发布动作不会在未明确批准时执行。

## 失败处理

影响分析缺失时返回方案设计；证据缺失时返回测试执行；需要人工决策时阻塞。
