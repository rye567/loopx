# 测试设计技能

## 目的

设计可执行测试用例，证明验收标准和风险缓解措施。

## 输入

- 需求产物、方案设计、规则快照、测试标准、项目 profile 命令和环境约束。

## 步骤

1. 将每条验收标准和适用必需规则映射到测试用例。
2. 补充边界、非法输入、权限和回归用例。
3. 定义唯一 `runId`/前缀、数据准备、执行入口、断言、清理和清理验证。
4. 评估失败重试、重复提交、幂等、并发、重复消息、分页和时间窗口的适用性。
5. 区分本地、CI 必需和人工检查，并生成符合 `test-plan.schema.json` 的产物。

## 输出

- 测试用例、结构化测试计划、覆盖矩阵、环境缺口和 `stage_result` 证据。

## 通过标准

- 无验收标准或适用必需规则缺少映射；每个测试都有准备、执行、断言、清理和清理验证；CI 必需检查不算本地通过。

## 失败处理

验收标准不可测试时返回需求或方案设计；覆盖或清理缺失时返回测试设计。
