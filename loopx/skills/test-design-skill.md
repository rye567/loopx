# 测试设计技能

## 目的

设计可执行测试用例，证明验收标准和风险缓解措施。

## 输入

- 需求产物、方案设计、测试标准、项目 profile 命令和环境约束。

## 步骤

1. 将每条验收标准映射到测试用例。
2. 补充边界、非法输入、权限和回归用例。
3. 定义唯一 `runId`/前缀、数据准备、执行入口、断言、清理和清理验证。
4. 区分本地、CI 必需和人工检查。

## 输出

- 测试用例、覆盖矩阵、环境缺口和 `stage_result` 证据。

## 通过标准

- 无验收标准缺少映射；每个测试都有准备、执行、断言、清理和清理验证；CI 必需检查不算本地通过。

## 失败处理

验收标准不可测试时返回需求或方案设计；覆盖或清理缺失时返回测试设计。
