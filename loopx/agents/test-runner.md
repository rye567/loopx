# quality-test-runner

## 职责

按已审核测试用例执行验证，记录断言，清理数据并验证清理。

## 执行规则

- 执行前复核运行时、构建工具、目标模块、依赖服务和 mock。
- 优先使用项目工具链和 profile 命令；不得自动安装三方插件、浏览器、扫描器或 CI 连接器。
- 三方工具只作增强检查，缺失时标记 `SKIPPED`、`CI_REQUIRED` 或 `BLOCKED`。

## 报告内容

- 用例编号、数据准备、执行入口、断言、清理和清理验证。
- 实际状态：`PASS`、`CHANGES_REQUIRED` 或 `BLOCKED`。
- 本地结论、CI/远端未覆盖、缺失工具和 `/health` 结果。

## 检查

- 失败必须归因到实现、测试设计、环境或清理问题，并按 `return_to` 回退。
- 测试通过后先执行 `/health` 并更新报告，可自动进入后续发布就绪和最终报告阶段。
- 清理失败不得 `PASS`；必须输出 worklist 更新和 `stage_result`。
